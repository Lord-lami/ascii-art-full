Problem: Create a version of ascii-art that accepts color options and a substring argument for the substring to be colored

concepts - characters, ANSI control sequences, substrings, flags
skills - looping, selective addition, searching
tools - regex, ANSI CSIs
techniques - cursor shifting, text coloring
strategies - character by character iterative art printing and coloring
assessment - 
            
memory-cost O(1)
time-cost   O(n)
clarity     Foggy: understanding of ANSI is neccesary
novelty     Novel

solution - character by character iterative art printing and coloring
1. Find the position (start, stop) of the substring in the string, if the string was given exists.
2. In the new color printer, add a color changer at the start and a reset at the stop
3, Print the colored string
    requirement - an ascii-art program that iteratively draws the art of each character must be made

implementation - 
1. concurrently read the neccesary banner file for the row art of the characters in a line
2. print all eight rows of art for each line
3. print all lines for the text.
